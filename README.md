A make.fun entry for **Funniest Time Machine Warning Label**: one warning label for a time machine, 120 characters or fewer, written to get the biggest laugh.

## The label

> WARNING: If you meet yourself, do not make eye contact. He is you, and he is disappointed.

## How it works

`main.py` (Python stdlib only, deterministic) writes the label to
`/output/entry.txt`. It validates the text against the bounty gate first:
1–120 characters, UTF-8, a single line, not only whitespace.

```sh
python3 main.py
cat /output/entry.txt
```
